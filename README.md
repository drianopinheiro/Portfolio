## 📌 Sobre o projeto

Este projeto é meu portfólio pessoal, desenvolvido para apresentar minha trajetória na área de tecnologia, meus conhecimentos, projetos e objetivos profissionais.

O site reúne minhas experiências de aprendizado e demonstra minha evolução como estudante e desenvolvedor.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Swiper.js
- Devicon
- Simple Icons

## ✨ Funcionalidades

- Apresentação pessoal e perfil profissional.
- Seção de habilidades e tecnologias.
- Carrossel de tecnologias.
- Carrossel de projetos.
- Linha do tempo com minha trajetória.
- Formação acadêmica e cursos.
- Indicadores de aprendizado contínuo.
- Objetivos profissionais.
- Alternância entre tema claro e escuro.
- Formulário de contato.
- Links para GitHub e LinkedIn.
- Layout responsivo.

## 💻 Projetos apresentados

- **Login Netflix Clone:** reprodução de uma interface de login inspirada na Netflix.
- **Jogo da Velha:** jogo interativo desenvolvido com JavaScript.
- **Cronômetro Responsivo:** cronômetro com interface adaptável.
- **GitHub:** acesso ao meu perfil e repositórios.

## 🆕 Recurso adicional

Um dos recursos adicionais do portfólio é a seção **Inteligências Artificiais**, que apresenta ferramentas de IA utilizadas como apoio nos estudos, na programação e no desenvolvimento de projetos.

Também implementei uma área de aprendizado contínuo para acompanhar visualmente minha evolução em diferentes tecnologias.

## ⚙️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
4. Para visualizar todos os recursos corretamente, mantenha a estrutura de pastas e os arquivos originais.
